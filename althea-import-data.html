Accepted formats: CSV or XLSX (up to 25 MB).

Code Manager export (required)

In ATLAS.ti, open the Code Manager and choose Export as Spreadsheet.

Accepted formats: CSV or XLSX (up to 25 MB).

Original files are stored exactly as uploaded. Althea works from a separate copy, so every quotation and code stays traceable to its source export.
